# وليد & دعاء — متابعة الوزن والوجبات والصحة

ويب أب شخصي لمتابعة الوزن والوجبات والمية والنوم لوليد ودعاء. فيه توليد يومي للوجبات وبوت تليجرام للإشعارات.

## الستاك
- **الواجهة:** Vite + TypeScript + صفحات HTML/CSS (بدون فريموورك)، وأنيميشن GSAP، وPWA
- **الباك إند:** Hono على Node 22، وقاعدة بيانات SQLite (`better-sqlite3` + Drizzle)
- **الجدولة:** `node-cron` بتوقيت `Asia/Kuwait`
- **التليجرام:** grammY (long polling)، ومفيش داعي لـ webhook
- **الوجبات:** Claude API (اختياري)، ولو مش متاح بيرجع لمكتبة وصفات داخلية (`server/recipes.ts`)

## الصفحات
| الصفحة | المحتوى |
|---|---|
| `/` | داشبورد: التقدم، الوصول المتوقع، المية، النوم، رسم الوزن، وجبات اليوم |
| `/meals.html` | 3 اختيارات لكل وجبة، والكميات بالجرام لكل شخص، والطريقة، وتبديل الاختيارات |
| `/log.html` | تسجيل المية (كوباية)، والنوم، والوزن الأسبوعي |
| `/pantry.html` | المخزن: الأصناف المتاحة، والوجبات مش بتستخدم غيرها |
| `/history.html` | رسوم بيانية وجداول |
| `/settings.html` | الأهداف، والنشاط، والإشعارات، وتجربة البوت |

## حساب السعرات
- **الحرق الأساسي:** Katch-McArdle لو نسبة الدهون معروفة (InBody)، وإلا Mifflin-St Jeor
- **الاحتياج اليومي** = الحرق × معامل النشاط، و**الهدف** = الاحتياج − 500
- **الحد الأدنى:** 90% من الحرق الأساسي، ومش أقل من 1500 للراجل و1200 للست
- **البروتين:** 1.6 جم/كجم من الوزن المستهدف للراجل، و1.4 للست
- **توزيع السعرات:** الفطار 30%، والغدا 40%، والعشا 30%
- كل ما وزن جديد يتسجل، السعرات بتتعدل تلقائيًا

> ⚠️ أرقام تقديرية، ومش بديل عن استشارة الطبيب.

## التشغيل محليًا
```bash
cp .env.example .env   # وعدّل القيم
npm install
npm run build
npm start              # http://localhost:3000
```
للتطوير: `npm run dev:server` و`npm run dev:client` (الـ Vite بيعمل proxy للـ `/api`).

## النشر (Dokploy)
- Build type: **Dockerfile**
- Volume: لازم يتربط بـ `/data`، لأن قاعدة البيانات `health.db` موجودة فيه
- Port: `3000`
- متغيرات البيئة: شوف `.env.example`. **الأسرار عمرها ما تترفع على GitHub.**

إشعارات الويب: ولّد المفاتيح بالأمر `npx web-push generate-vapid-keys`، وحطها في `VAPID_PUBLIC_KEY` و`VAPID_PRIVATE_KEY`.
